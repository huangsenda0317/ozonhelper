# OZON 助手操作说明

## 1. 选品排行榜

> 目前都是 mock 数据

**路径：** OZON助手 → 选品排行榜（`/ozon-assistant/rankings`）

五个榜单 Tab：商品榜、类目榜、品牌榜、卖家榜、机会榜。

上面可以筛排序、类目、FBO/FBS、关键词，表格支持分页。

### 采集商品

- **商品榜：** 每行有「添加采集」
- **其他榜：** 采的是代表商品（有 top SKU 的那条）
- 勾选多行后，Tab 栏右边「批量采集」才会亮，点了会进采集页

---

## 2. 商品采集

**路径：** 商品采集 Tab（`/ozon-assistant/collection`）

相当于采集箱，从排行榜加进来的货都在这。

| 类型 | 操作 |
|------|------|
| 筛选 | 关键词、采集时间、来源平台（OZON/1688）、加工状态（已创建/未创建） |
| 单行 | 详情、编辑、比价、删除 |
| 批量 | 勾选后「批量加工」或「批量删除」 |

- **批量加工：** 状态变「已创建」，同时在加工池生成加工单
- 已经在加工池的会跳过，toast 会提示
- 详情/编辑/比价是右侧抽屉

---

## 3. 商品加工

**路径：** 商品加工 Tab（`/ozon-assistant/processing`）

四个状态 Tab：加工池 / 加工中 / 加工成品 / 加工失败

列表可以筛关键词、来源、创建时间。勾选后能批量删；在「加工成品」Tab 还能 **批量加入待上架**。

点「编辑加工」进详情页（`/ozon-assistant/processing/[id]`），主要干这几件事：

1. **AI 一键优化** — 顶栏蓝色按钮，自动改标题、标签、描述（中文）
2. 手动改字段 → **保存信息**
3. 标题填好后 → **加入待上架**
4. 想重来 → **重新创建加工单**（文案保留，状态回加工池）

**关于中文/俄文：** 编辑页全是中文，顶栏有提示——上架前会自动转俄文，现在不用自己翻译。

> AI 优化目前是 mock（等约 1.5 秒出结果），改完记得保存。图片素材区是占位，AI 改图还没接进来。

删加工单会把对应采集项的加工状态退回「未创建」。

---

## 4. 商品管理

**路径：** 商品管理 Tab（`/ozon-assistant/management`）

目前就 **待上架商品** 这一个列表。

加工成品「加入待上架」后会出现在这。可以筛关键词、来源状态、店铺、加入时间。

| 类型 | 操作 |
|------|------|
| 单行 | 详情、移出待上架 |
| 批量 | 批量上架（mock）、移出待上架 |

详情页（`/ozon-assistant/management/[id]`）看基本信息、库存、浏览量这些，只读。

移出待上架后，可以去加工页再次加入。

---

## 完整流程

```
排行榜找货 → 添加采集 / 批量采集
    ↓
采集页确认 → 批量加工
    ↓
加工页编辑 → AI 优化 → 保存 → 加入待上架
    ↓
管理页 → 批量上架
```
